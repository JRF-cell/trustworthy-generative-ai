## Lancer le TD2

Python 3.10 ou plus récent suffit, sans bibliothèque à installer ni clé API.

```bash
cd td2
python analyse_td2.py
python -m unittest test_td2.py
```

Le TD2 utilise les traces du TD1 sans refaire d'appels aux modèles.
